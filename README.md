# LangChain / LangGraph 学习档案

从第一次调用大模型，到工具、记忆、RAG、MCP、异步服务、质量评测和毕业练习的逐日学习记录。**这是学习参考仓库，不是宣称生产可用的 Agent 框架。**

目前公开 **Day01—Day35，共 443 份逐日代码、笔记、示例资料和练习产出**。这是本地文件实际存在的范围；尚无 Day36—Day45，不能把日历上的学习时长等同于课程编号。后续有新的真实产出再补充。

## 从哪里开始

- [逐日学习索引](docs/learning-index.md)：35 天的主题、代码、笔记和文件数量。
- 每天的 `python/` 保留分步练习，`notes/` 保留复习总结和最后代码的详细解读。
- `html/`、`javascript/`、`css/` 保留浏览器练习；示例资料、配置、评测题和生成工具保留在对应 Day。
- [公开文件清单](docs/archive-manifest.json)：每份归档文件的 SHA256，以及是否做过脱敏。
- [历史运行摘要](docs/historical-run-summaries.json)：从已有报告提取的少量状态与数值，不包含原始对话和检索正文。
- [最后三天的独立 Demo](docs/capstone.md)：它只是这段学习历程的一个成果，不代表整个仓库。

## 如何使用逐日代码

先阅读当天笔记，再按步骤阅读和运行对应脚本。请从仓库根目录运行，以保留原练习的跨 Day 导入和相对目录关系。

```bash
git clone https://github.com/as2132r2/learning-agent.git
cd learning-agent
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
# 在编辑器填写你自己的模型配置；不要提交 .env
python day01/python/hello.py
```

上面的安装只覆盖最后 Demo 的基础依赖，**不覆盖所有 35 天练习**。不同练习另有 aiohttp、FastEmbed、SQLite 向量扩展、MCP SDK 等依赖，请遵循当天笔记；不要认为一次安装能让全部历史脚本直接运行。旧练习可能需要旧版本接口，依赖弃用和错误修复本身也是学习记录。

Day35 的 [依赖记录](day35/requirements.txt) 是当时环境直接依赖的快照，不是整个学习档案的完整锁文件。真实模型需要联网和密钥，可能收费；首次 Embedding 可能下载模型。

知识库和运行数据库没有随仓库分发。后续练习依赖前序索引时，应先按笔记构建；没有提供原始私人上传资料，相关检索结果不会与原学习现场完全一致。发布制品、签名和备份也需要自行生成，不能将历史报告摘要当成当前验证结果。

## 公开范围与隐私

原学习目录没有被改动；这里是经过筛选和脱敏的公开副本，而不是整盘备份。

保留学习代码、笔记、前端练习、原创测试资料、生成的测试 PDF/预览、配置模板和评测题。未公开：

- 模型密钥、真实访问令牌、签名私钥与 HMAC 密钥；
- 聊天/账户/反馈数据库、会话文件和完整原始日志；
- 私人上传文档及其处理副本；
- 虚拟环境、模型缓存、字节码、压缩发布包和数据库备份。

原日志和报告仅保留可安全抽取的状态/数值摘要，不复制对话、证据正文和可能包含用户信息的上下文。少量笔记中的令牌与个人绝对路径已替换为占位符。教学用固定测试令牌不是生产凭证，切勿在真实服务复用。
