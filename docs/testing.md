# 测试与验证说明

## 可重现的离线验收

`tests/test_acceptance.py` 从毕业项目验收整理而来，G01—G12 使用 Fake 模型与 Fake 检索，但实际运行 LangGraph、ToolNode、SQLite 和文件写入。

| 编号 | 验证点 |
| --- | --- |
| G01 / G02 | 同会话记忆、不同会话隔离 |
| G03 | add → multiply，ToolMessage ID 对应，结果 72 |
| G04 / G05 | 来源引用、空证据不调用回答模型 |
| G06 / G07 | 批准后写入、拒绝不写且不可重试 |
| G08 | 关闭并重建连接与图后恢复聊天和审批 |
| G09 | 数字字符串、布尔值、无穷大、越界、额外参数被拒绝 |
| G10 | 临时故障重试、同内容幂等复用、冲突不覆盖 |
| G11 | 跨会话、错误哈希、重复审批被拒绝 |
| G12 | 权限错误不可重试，临时错误最多重试两次 |

`tests/test_retrieval.py` 使用小型注入向量验证真实 SQLite/FTS5 索引、融合顺序、缓存和内容变更重建，不验证 BGE 语义质量。

`tests/test_process.py` 用两个独立 Python 进程共享临时目录，检查名字、待审批快照和文件写入的恢复。

## 真实模型验证范围

原课程毕业项目曾完成 5 项真实 DeepSeek 验收（记忆、隔离、计算、RAG、恢复）。这些历史结果**不等同于重构后开源版的完整实时验收**，也不作为本仓库 CI 成绩。公开仓库不携带原始对话日志或私人知识库。

若要验证开源版真实模式，请自行配置密钥并检查：

1. 姓名追问、重启恢复以及另一个 session_id 的隔离。
2. `请计算(20+4)*3。` 确实执行两个工具，结果 72。
3. `根据资料解释RAG。` 检索到 `rag.txt`，回答引用存在且内容被资料支持。
4. 不在资料中的问题应说明资料不足；扩大问题集再调整精排阈值。
5. 提案后退出，重启批准；拒绝与跨会话审批不能写文件。

模型输出有随机性，字段解析可能失败；失败不应被描述为成功。请勿提交含密钥或私人内容的验证日志。
